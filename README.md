# Mnist-CNN-Classifier

A lightweight Convolutional Neural Network implementation in TensorFlow/Keras for handwritten‐digit recognition on the MNIST dataset.

---

## 📋 Overview

This project demonstrates how to:

1. **Load & preprocess** the MNIST dataset  
2. **Build** a LeNet-style CNN architecture  
3. **Train** the model with real‐time validation  
4. **Evaluate** and **infer** digit classes on new images  

The code is organized as a single Python script (`classifier.py`) with clearly defined functions for each step.

---
